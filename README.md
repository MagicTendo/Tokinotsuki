# Tokinotsuki

![Tokinotsuki](https://tokinotsuki.rf.gd/img/tokinotsuki-head.png)

> *A very polyvalent Discord bot entirely written in JavaScript !*

## 🛠️ Features

The main purpose of Tokinotsuki is to offer as much functionalities as possible while being totally free. Every commands are grouped in 10 categories :

- Information (help, useful links, details about user, etc.).
- Fun (anime, video games statistics, random, etc.).
- Games (blackjack, minesweeper, custom games, etc.).
- Moderation (kick, ban, server security, etc.).
- Utility (calculator with graphic mode, units converter, QR code, etc.).
- Learning (flags, japanese syllabaries, mental arithmetic, etc.).
- Useless (dumb commands with no purpose).
- Server (only for [Yunayunori's server](https://discord.gg/DYQutQvbSu), like the XP system).

The full list is given [here](https://tokinotsuki.rf.gd/commands.html) and with the `/help` command.


## ✉️ Inviting

There is now two ways you can try Tokinotsuki ! By clicking [this link](https://tokinotsuki.rf.gd/invite), Discord will ask if you want to have the bot on a server or on your account.
- A bot on a server works like a regular user except you can interact with it with slash command, like `/help` which list every commands you can do.
- A bot on your account allows you to use it anywhere you want, however, you can't do every commands due to some limitations and only you can see her responses.


## 💾 Selfhosting

Here's a little guide explaining how to selfhost Tokinotsuki.
First, clone or download the repository, then get a LTS version of Node.js (20 or above is recommended). After that, install PNPM latest and type `pnpm install` on your terminal inside the project, this should install every dependencies in the right version. Next, copy the [.env.example](./.env.example) file, rename it to `.env`, and fill it. You probably don't need everything the file is asking for, in that case, remove the part in the code asking the keys you don't need. If you didn't already, create an application on the Discord Developer Portal and make it as a bot, this is how you get a bot token. Finally, when the `.env` is ready, you can launch the bot with `node .` ! It is as easy as that, thanks JavaScript !


## 🎫 Help

If your need is to report a bug, to submit a suggestion, to indicate a misspelling or a simple action to your account (like data deletion for you account), then you can simply use the `/report` command.
Otherwise, you can join the [official Discord support server](https://discord.gg/ZNvTCvNGbZ) for further help.
