# Contributing

The best way you can contribute to this project is simply by reporting bugs or by giving suggestion either with the `/report` command or on the [official Discord support server](https://discord.gg/ZNvTCvNGbZ).
I don't recommend to try contributing by merge requesting because I have very specific rules I use when writting code (for example, the imports have an order for me, I never use var but always double quotes, etc.), and I hate inconsistency (yes I'm perfectionist, especially on code, that's why, sorry about this).
However, if the project starts to have an international community, I'll be totally open for translation contributions, but that's for later for now !
