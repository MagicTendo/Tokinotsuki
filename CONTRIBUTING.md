# 💖 Contributing

The best way you can contribute to this project is only by reporting bugs, or by giving suggestions, either with the `/report` command, or on my [Discord server](https://discord.gg/DYQutQvbSu).

I don't recommend to try contributing by merge requesting, because I have very specific rules when writing code (like the imports must be ordered, I avoid using var, etc.), and I hate inconsistency because of my perfectionism.

However, if the project starts to have an international community, I'll be totally open for translation contributions! But that's not for now.
